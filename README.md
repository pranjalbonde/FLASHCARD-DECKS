FLASHCARD-DECKS
A responsive web-based flashcard learning application built with HTML, CSS, and JavaScript. Users can create, manage, and review custom flashcards to make studying more interactive and efficient. The project features a clean, intuitive UI and demonstrates core front-end development,DOM manipulation, and JavaScript for dynamic content management.

Features

- Create multiple flashcard decks
- Add, edit, and delete flashcards
- Study cards using an interactive flip animation
- Shuffle cards for better revision
- Track your progress while studying
- Save all data in the browser using Local Storage
- Export and import flashcard decks
- Light and Dark mode support
- Responsive design for desktop and mobile
- Generate flashcards from notes using AI (optional)

 Built With
- HTML5
- CSS3
- JavaScript (Vanilla JS)

Why I Built This

As a student, I wanted a quick free way to revise important concepts. This project was created to make revision easier by allowing users to build their own flashcard decks and review them anytime. It also gave me experience with DOM manipulation, Local Storage, and creating a responsive user interface.

How to Run

1. Clone this repository

```bash
git clone https://github.com/pranjalbonde/FLASHCARD-DECKS/blob/main/flashcard-local.html
```

2. Open the project folder.

3. Open the `flashcard-local.html` file in your browser.
